# AI Explorer 0.5 — спецификация

## Терминальный Kimi Code

### Цель

Предоставить полный интерактивный Kimi Code CLI внутри OpenIDE без промежуточного ACP-интерфейса.

### Поведение

- Каждая вкладка AI Explorer содержит настоящий PTY-терминал с Kimi Code TUI.
- Команды запускаются в рабочей директории текущего проекта.
- Поддерживаются клавиатура, цветной вывод, интерактивные меню, slash-команды и запросы разрешений Kimi Code.
- Закрытие вкладки завершает связанный терминальный процесс.

### Сессии

- «Новая сессия» запускает `kimi`.
- «Продолжить последнюю» запускает `kimi --continue`.
- Боковая панель читает локальный индекс Kimi Code и показывает только неархивные сессии текущего проекта, отсортированные по времени изменения.
- Список содержит названия и даты сессий, поддерживает поиск и обновление.
- Двойной клик или Enter открывает выбранную сессию через `kimi --session <id>`.
- «Выбрать сессию…» может запускать штатный интерактивный выбор `kimi --session`.
- Внутри терминала доступны `/sessions`, `/new`, `/compact` и остальные команды CLI.
- Сессии хранятся самим Kimi Code и доступны также вне OpenIDE.

### Вставка изображений

- `Cmd+V` вставляет изображение из системного буфера обмена через штатную команду Kimi Code `Ctrl+V`.
- `Ctrl+V` передаётся напрямую в Kimi Code и не вызывает действие VCS Operations в OpenIDE.
- Текстовая вставка через `Cmd+V` сохраняет обычное поведение терминала.

### Ссылки в терминале

- HTTP/HTTPS URL из вывода Kimi Code регистрируются как штатные гиперссылки JediTerm.
- Активация ссылки открывает её в системном браузере; финальная пунктуация не включается в адрес.

### Граф файлов

- Кнопка «Граф файлов» переключает вкладку между живым терминалом и графом без перезапуска Kimi Code.
- Граф читает вызовы инструментов из локальных `wire.jsonl` текущей сессии и обновляется во время работы.
- Радиальная карта группирует активность по станциям: файлы проекта, Markdown-документация, скиллы, конфигурация, терминал, сеть и субагенты.
- Счётчики, износ лучей, импульсы и журнал под картой показывают текущую и завершённую активность; оформление адаптировано из Lot Map (MIT).
- Маршрут между последними станциями повторяет геометрию Lot Map и исчезает через 40–60 секунд; светятся только активные и недавно использованные узлы, подписи защищены обводкой от пересекающих линий.
- Щелчок по станции открывает список её файлов, сайтов или вызовов с количеством обращений; файлы открываются в OpenIDE, сайты — в браузере.
- Доступны масштабирование карты и возврат из детального списка к орбитам.
- При смене сессии граф очищается и строится заново по её журналу.

### Навигация по ресурсам

- Рядом с Chats доступны вкладки Skills, Settings и MCP; боковой JCEF-интерфейс чатов сохраняется.
- Skills показывает проектные, глобальные и дополнительные каталоги, вложенность файлов и локальные Markdown-ссылки. Поиск учитывает названия, описания и пути.
- Settings показывает глобальные инструкции и настройки, а также проектные AGENTS.md/CLAUDE.md с относительными каталогами и ссылками.
- MCP разделяет глобальные и проектные серверы, показывает включённость, способ подключения и переопределение одноимённых записей. Секретные поля конфигурации в JCEF не передаются.
- Файлы открываются для чтения и редактирования в основном редакторе OpenIDE. Деревья обновляются после изменения файлов и сохраняют свёрнутые группы.

### Заголовки сессий

- Открытая вкладка получает актуальное название из локального индекса Kimi Code без закрытия и перезапуска терминала.
- Ручное переименование также обновляет существующую вкладку на месте.

### Добавление выделенного кода

- Действие «Добавить в AI Explorer…» открывает текущий терминал или создаёт новый.
- Сформированный текст с путём, строками и кодом вставляется в текущее поле ввода Kimi Code без автоматической отправки.

### Ограничения

- ACP, JCEF-чат, собственные карточки инструментов и отдельный граф субагентов не используются.
- Плагин читает метаданные сессий напрямую из локального хранилища Kimi Code, не изменяя их.

### Критерии приёмки

- Плагин собирается с зависимостью от штатного Terminal-плагина OpenIDE.
- Все три сценария запуска открывают работающий Kimi Code TUI.
- Предыдущую сессию можно выбрать и продолжить без ACP.
- Закрытие вкладки не оставляет запущенный процесс Kimi.
- `Cmd+V` вставляет скриншот в поле ввода Kimi Code, а обычный текст вставляется как раньше.
- Граф показывает обращения к файлам текущей сессии и открывает выбранный файл в OpenIDE.
